Block art

Every sculpture here comes from one set of box coordinates in assets/blocks.js, drawn two ways. Flat SVG via <fw-blocks>, or rendered in WebGL with real cast shadows via <fw-blocks-3d>, which ships hatched. Both renderers agree, so the flat one stands in until three.js loads. Use renderToDataURL() for a PNG at post size. Not linked from the site; it is here for the social builder.
